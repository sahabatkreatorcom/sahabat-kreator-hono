# Video Demo Script: Meta — Instagram (via Facebook Login)

**Permission:** instagram_basic, instagram_content_publish
**Durasi target:** 2-3 menit
**File name:** `demo-meta-instagram.mp4`

## ⚠️ Warnings

- [ ] Pastikan Page Facebook punya Instagram Business Account yang tertaut

## ❌ Larangan (Jangan Ditampilkan)

- [ ] Jangan gunakan akun IG personal (harus Business/Creator)
- [ ] Jangan tampilkan password IG

## Scenes

### Scene 1: Connect Instagram Business
**Durasi:** 40 detik

| Time | View | Action | Notes |
|------|------|--------|-------|
| 0:00-0:15 | Halaman Connect Account | Klik "Connect Instagram" (pilih mode Facebook Login) | Jangan pilih 'Instagram Login' (itu mode standalone) |
| 0:15-0:30 | Consent Facebook muncul | Login → grant permissions | Perhatikan: Tampilkan scope instagram_basic, instagram_content_publish |
| 0:30-0:45 | Pilih Page dengan Instagram Business Account tertaut | Dropdown muncul → pilih Page yang punya IG tertaut | Klik 'Continue' atau 'Connect' |
| 0:45-0:55 | Sukses connect, tampilkan username IG | Tunjukkan profil IG di dashboard Sahabat Kreator |  |

### Scene 2: Create Instagram Post
**Durasi:** 45 detik

| Time | View | Action | Notes |
|------|------|--------|-------|
| 0:55-1:10 | Composer / Create Post | Klik "Create Post" |  |
| 1:10-1:35 | Form Instagram post | Isi form post | Pilih target: Instagram Business Account
Upload media (foto/carousel)
Tulis caption dengan hashtag
Set jadwal tayang |
| 1:35-1:50 | Preview carousel (jika multi-image) | Swipe horizontal untuk tunjukkan semua slide | Klik "Schedule" |

### Scene 3: Verify Instagram Post
**Durasi:** 30 detik

| Time | View | Action | Notes |
|------|------|--------|-------|
| 1:50-2:05 | Status post di kalender (Scheduled → Published) | Tunggu atau time-lapse |  |
| 2:05-2:20 | Buka Instagram app/browser | Buka profil IG yang terhubung | Scroll ke post yang baru tayang. Tunjukkan caption, like, comment |
| 2:20-2:30 | Kembali ke Sahabat Kreator | Tunjukkan post history dengan status 'Published' |  |

*Dokumen ini dibuat untuk Sahabat Kreator.*
